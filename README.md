# Stefan's App Store

Personal AltStore source hosting iOS apps built by Stefan.

## Add this source to AltStore

In AltStore on your iPhone: **Browse → Sources → + → Add Source URL**

```
https://balancenowdeveloper.github.io/stefans-appstore/apps.json
```

## Structure

- `apps.json` — AltStore source manifest (apps + versions)
- `apps/` — hosted IPA files
